## 🌟 Executive Overview

**CelebrateOS** is an enterprise-grade AI event intelligence workspace designed after modern celebration platforms (**Partiful**, **WithJoy**, and **Luma**). It unifies creative direction, financial budget governance, countdown execution timelines, supplier pipelines, and attendee hospitality into a cohesive, zero-latency reactive canvas.

---

## 🚀 Key Modules & Capabilities

### 1. ✦ GenAI Celebration Creative Director
* **Natural Language Attribute Parsing:** Intelligently extracts exact hard budget limits (e.g. `₹ 10,00,002`, `$5,000`), custom attendee capacity (e.g. `157 executive delegates`), and bespoke decor requirements.
* **Instant Thematic Synthesis:** Automatically architects event titles, subtitles, color palettes, sonic playlists, and expense categories from natural language prompts.
* **Trending Concept Chips:** One-click instant synthesis for *👑 Royal Wedding Gala*, *🎂 30th Rooftop Disco*, *🏢 Executive Tech Keynote*, and *🎪 Boho Eco-Carnival*.

### 2. 🎨 Theme & Aesthetic Studio (Partiful & WithJoy Benchmarked)
* **Atmospheric Palette:** Midnight Velvet Caviar (`#08070F`), Partiful Electric Violet (`#8B5CF6`), Champagne Rose (`#FB7185`), and Luminous Amber Gold (`#F59E0B`).
* **Interactive Chromatic Swatches:** Click-to-copy HEX codes with real-time OS clipboard integration.
* **Curated Scenography, Sound & Attire:** Master decor guidelines, minute-by-minute sonic atmosphere, and guest dress code prompts.

### 3. 📊 Dynamic Budget Governance & Forex Engine
* **Real-Time Multi-Currency Forex Engine:** Live market rate conversions across **`₹` (INR)**, **`$` (USD)**, and **`€` (EUR)** (`₹83.50/$` and `₹90.50/€`).
* **Interactive Chart.js Donut Visualization:** Live reactive rendering of category splits and budget distribution.
* **Velocity Burn Bar & Safety Runway:** Real-time burn indicators, cost-per-attendee calculations, and contingency buffers.
* **Ledger Editing & Auto-Rebalancing:** In-line editing of planned allocations and actual payments with zero-drift proportional auto-rebalancing.

### 4. ⏳ Milestone Reverse-Countdown Roadmap
* **Reverse Chronology:** Phased roadmap tracking deliverables from *3 Months Out*, *1 Month Out*, *2 Weeks Out*, *48 Hours Out* to *Day Of Event*.
* **Achievement Velocity:** Live progress counter (`X / Y Achieved`) with animated strikethrough state preservation.

### 5. 🤝 Supplier Coordination Matrix
* **Contracting Status Pipeline:** Dynamic Kanban pipeline tracking states (`Not Started` ➔ `In Discussion` ➔ `Booked` ➔ `Paid`).
* **Direct Vendor Communication:** Integrated quote comparison and instant `mailto:` vendor dispatch.

### 6. 🥂 Guest Hospitality & RSVP Management
* **Pacing vs. Hard Venue Ceiling:** Real-time tracking of confirmed heads vs target venue capacity.
* **Dietary Profile Badges:** Tracks *Vegan*, *Gluten-Free*, *Vegetarian*, and *Halal* catering requirements.

## 💻 Quick Start & Local Preview

Clone the repository and run any standard local server:

```bash
# Clone repository
git clone https://github.com/GLITCHGLORY-7/PROMPT-WARS.git
cd PROMPT-WARS

# Run with Python HTTP server (zero build tools required)
python -m http.server 5173

# Open in browser
# http://localhost:5173
```

Alternatively, deploy directly to **Vercel**, **Netlify**, or **GitHub Pages** with one click.
